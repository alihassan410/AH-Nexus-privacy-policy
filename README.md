# AH-Nexus privacy policy

A responsive, self-contained HTML privacy policy for the AH-Nexus Windows desktop app. No build tools, dependencies, JavaScript, or external assets are required.

## Publish for free with GitHub Pages

1. Push these files to the `main` branch of [this repository](https://github.com/alihassan410/AH-Nexus-privacy-policy).
2. Open the repository's **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select **main** and **/ (root)**, then click **Save**.
5. Wait for GitHub Pages to finish publishing.

The published privacy-policy URL will be:

https://alihassan410.github.io/AH-Nexus-privacy-policy/

Use that URL for the Microsoft Store privacy-policy field once the page is live. The repository must remain public to use GitHub Pages on GitHub Free. See [GitHub's Pages setup documentation](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site).

## Editing and preview

Open `index.html` directly in a browser to preview. Edit its policy text and update the effective/last-updated date whenever data handling changes. Commit and push updates to `main`; GitHub Pages will republish them.

Contact is the repository's public GitHub Issues page, as selected by the project owner. Keep Issues enabled and do not ask users to post sensitive information.

The policy describes the implementation reviewed on October 15, 2026, including local inference, SQLite/WebView2 storage, optional voice and awareness, and model downloads. Review it against future releases before publishing app changes.
